파일은 브라우저 안에서만 읽습니다. 이 사이트에는 서버도, 업로드 기능도, 분석 코드도 없습니다. 창을 닫으면 아무것도 남지 않습니다.

카카오톡 대화 내보내는 법
안드로이드
대화방 → 오른쪽 위 ☰ → 설정(톱니) → 대화 내용 내보내기 → 텍스트만 보내기 → 파일 앱 등으로 저장
아이폰
대화방 → 오른쪽 위 ☰ → 설정(톱니) → 대화 내용 내보내기 → 텍스트 메시지만 보내기 → 파일에 저장
PC (윈도우 · 맥)
대화방 오른쪽 위 ⋮ → 대화 내용 → 내보내기 → 텍스트(.txt) 또는 CSV로 저장
